# SDMini 游戏设计文档（GDD）

> 版本：v1.0（MVP）
> 平台：微信小游戏（竖屏）
> 类型：极简塔防 / 单局制
> 玩法参考：Simple Defense

---

## 1. 项目概述与目标用户

### 1.1 一句话定位

SDMini 是一款运行在微信小游戏平台上的**极简塔防**游戏。玩家在固定路径旁建造与升级防御塔，抵御 10 波敌人进攻，守住基地生命即可获胜。

### 1.2 核心特征

- **竖屏单手操作**：设计分辨率 720×1280，采用 `FIXED_WIDTH` 适配策略，适配各类手机屏宽。
- **零美术资源**：全部画面使用引擎 `Graphics` 与纯色节点程序化绘制，不依赖任何图片资源。
- **极简几何风格**：以网格、纯色色块、几何图形构成视觉语言。
- **单局时长约 5–8 分钟**：一局 = 一张地图 + 固定 10 波敌人。

### 1.3 目标用户

| 用户画像 | 特征 | 需求 |
|---|---|---|
| 轻度休闲玩家 | 通勤 / 碎片时间，单手可玩 | 上手快、单局短、无需长期养成 |
| 塔防老玩家 | 熟悉建造 / 升级 / 波次机制 | 明确的策略取舍与数值反馈 |
| 微信生态用户 | 无需下载、即点即玩 | 低门槛、加载快 |

### 1.4 MVP 范围

**包含**：
- 单张固定路径地图
- 3 种防御塔（箭塔 / 炮塔 / 冰塔），每种可升至 3 级
- 3 种敌人（小兵 / 重甲 / 疾行）
- 固定 10 波敌人
- 金币经济与升级
- 胜负结算
- 本地存档

**不包含（后续规划）**：多地图、多关卡、成就系统、排行榜、内购、社交分享。

## 2. 核心玩法循环

```
┌─────────────────────────────────────────────────────┐
│                    单局核心循环                        │
│                                                       │
│   观察波次预告 ──► 建造 / 升级塔 ──► 敌人出怪           │
│        ▲                                     │        │
│        │                                     ▼        │
│        │                              塔自动索敌开火     │
│        │                                     │        │
│        │                                     ▼        │
│        └──── 获得金币/波次奖励 ◄──── 击杀 / 漏怪扣血     │
│                                                       │
└─────────────────────────────────────────────────────┘
```

玩家在**准备阶段**预先布防，在**战斗阶段**观察漏怪情况并动态调整（补塔 / 升级 / 卖塔），通过经济滚雪球应对逐波增强的敌人，最终守住 20 点基地生命通关。

## 3. 单局流程

| 阶段 | 触发 | 玩家可做 | 系统行为 |
|---|---|---|---|
| **准备** | 第一波前 5 秒；波与波之间 6 秒 | 建造 / 升级 / 卖塔；点击「立即开始」提前出怪 | 倒计时准备时间 |
| **建造** | 常态，随时可进行 | 点击空格选择塔并建造 | 扣除金币、生成塔 |
| **出怪** | 准备计时结束或玩家提前开始 | 观察战场、实时调整 | 按波次表生成敌人，塔自动索敌开火 |
| **波间** | 本波全部敌人被清空或被漏掉后 | 同上 | 发放本波清完奖励，进入下一波准备 |
| **胜负** | 基地生命 ≤ 0 / 第 10 波全部清完 | — | 弹出结算面板 |

### 3.1 关键规则

- **第一波准备时间**：5 秒。
- **波与波之间准备时间**：6 秒。
- **提前开始奖励**：准备阶段点击「立即开始」立即出怪，额外获得 `剩余准备秒数 × 2` 金币。
- **每波清完奖励**：`20 + 波数 × 5` 金币（清空全部出怪后发放）。

## 4. 操作与交互说明

### 4.1 建造流程

1. 点击**空的可建格**（非路径格、无塔） → 弹出建造菜单。
2. 建造菜单展示 3 种塔的图标、造价、**是否可负担**（金币不足时置灰）。
3. 选择一种塔 → 在该格建造，扣除对应造价。

### 4.2 升级 / 出售流程

1. 点击**已有塔的格子** → 弹出升级 / 出售菜单。
2. **升级**：满足金币条件时升至下一级（最高 3 级），扣除升级费用。
3. **出售**：返还该塔**累计投入金币**（建造费用 + 已支付的升级费用）的 **70%**（向下取整）。

### 4.3 顶部 HUD

顶部 HUD 常驻显示：**金币、基地生命、当前波次、暂停按钮、倍速按钮**。

| 控件 | 功能 |
|---|---|
| 金币 | 显示当前金币数量 |
| 基地生命 | 显示基地剩余生命 / 上限（20） |
| 当前波次 | 显示「第 N 波 / 共 10 波」 |
| 暂停 | 暂停 / 恢复游戏逻辑 |
| 倍速 | 切换游戏速度（如 1× / 2×） |

### 4.4 索敌策略

防御塔默认攻击**射程内离基地最近（路径进度最大）**的敌人，即优先拦截最接近终点的威胁。

- **网格**：9 列 × 13 行，格子 80×80 px。
- **路径**：固定折线（S 形），路径格**不可建塔**，非路径格**可建塔**。

### 6.2 路径坐标（网格坐标 `列,行`）

```
(-1,6) → (1,6) → (1,2) → (4,2) → (4,10) → (7,10) → (7,6) → (9,6)
```

- 从 `(-1,6)` **进入屏幕**（左侧屏幕外）；
- 从 `(9,6)` **离开屏幕**（右侧屏幕外）。

## 7. 塔与敌人设计意图

### 7.1 三种塔的分工

| 塔 | 角色定位 | 设计意图 |
|---|---|---|
| **箭塔（arrow）** | 通用单体输出 | 造价低、性价比稳定的「主力输出」，用于对无甲小兵的高频点杀 |
| **炮塔（cannon）** | 高单发 / 范围清杂 | 单发伤害高、攻速慢，配范围爆炸，**对高护甲/密集敌人收益最大** |
| **冰塔（frost）** | 控制辅助 | 直接伤害低，但减速能**延长敌人在所有塔射程内的停留时间**，间接放大整体 DPS |

**为什么是这 3 种**：构成「输出（单体）/ 爆发（范围）/ 控制（减速）」的经典三角，覆盖塔防最基本的策略决策；3 种数量足够形成塔型搭配取舍，又不增加新手的认知负担。

### 7.2 三种敌人的分工

| 敌人 | 角色定位 | 设计意图 |
|---|---|---|
| **小兵（grunt）** | 标准单位 | 生命/速度均衡，作为数值基准与数量压力来源 |
| **重甲（tank）** | 高生命 + 护甲 | 检验玩家输出是否「打得动」，逼迫升级或补充高单发塔（炮塔） |
| **疾行（runner）** | 高速低生命 | 检验控制与响应，逼迫玩家提前布防 / 用冰塔减速，形成节奏压力 |

**为什么是这 3 种**：分别代表「量」「坦」「速」三种威胁维度，与三种塔形成天然的克制/协同关系，组合出的 10 波能提供清晰的难度递进。

## 8. 胜负条件与结算

### 8.1 胜负条件

- **失败**：基地生命 ≤ 0。
- **胜利**：第 10 波全部敌人被清完。

### 8.2 经济与生命基线

| 项 | 数值 |
|---|---|
| 初始金币 | 150 |
| 基地生命 | 20 |
| 每波清完奖励 | 20 + 波数 × 5 |
| 第一波准备时间 | 5 秒 |
| 波间准备时间 | 6 秒 |
| 提前开始奖励 | 剩余准备秒数 × 2 金币 |
| 卖塔返还 | 该塔累计投入 × 70%（向下取整） |

### 8.3 结算

- 弹窗展示：胜利 / 失败、到达波次、最终金币、剩余基地生命。
- 结算后写本地存档（最高记录等），并回到主界面。

## 9. 美术方向

### 9.1 风格定义

- **极简几何**：所有元素由纯色矩形 / 圆形 / 线段构成，无贴图、无美术资源。
- **程序化绘制**：使用引擎 `Graphics` 组件在运行时绘制网格、路径、塔、敌人、血条、子弹。
- **高辨识度配色**：以深色背景衬托高饱和几何色块，保证在手机上小尺寸也清晰可辨。

### 9.2 配色方案

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#1B2430` | 深色底，降低视觉疲劳 |
| 路径 | `#3A4A5E` | 灰蓝，与背景区分 |
| 可建格 | `#242E3B` | 比背景略亮，形成网格感 |
| 箭塔 | `#4FC3F7` | 亮蓝 |
| 炮塔 | `#FF7043` | 橙红 |
| 冰塔 | `#81D4FA` | 浅冰蓝 |
| 敌人 | `#EF5350` | 红，警示色 |
| 血条 | `#66BB6A` | 绿色，表示剩余生命 |
